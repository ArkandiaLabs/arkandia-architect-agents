# Arkandia Architect Agents

Multi-agent platform on Microsoft Agent Framework: architecture review + incident intelligence.

Built in public, phase by phase, on .NET 10 with OpenAI + Anthropic through `Microsoft.Extensions.AI`, and Microsoft Foundry.
